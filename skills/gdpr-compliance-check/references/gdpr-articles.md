# GDPR 核心条款速查

面向合规检查的条款索引：每条给出**义务 → 检查点 → 违反后果层级**。

## 一、适用范围

| 条款 | 要点 | 检查点 |
|---|---|---|
| Art.2 | 属地/属物范围：全自动或半自动处理，或构成归档系统的人工处理 | 处理活动是否落入 GDPR |
| Art.3(1) | 欧盟境内机构的处理活动，不论处理地在哪 | 是否在欧盟设有机构 |
| Art.3(2) | 向欧盟居民提供商品/服务，或监控其行为 → 同样适用 | 是否主动面向欧盟用户（语言、货币、运费、.eu 域名等） |
| Art.27 | 无欧盟机构但受 Art.3(2) 管辖 → 必须指定欧盟代表 | 是否已在隐私政策公布代表信息 |
| Art.28 | 委托处理者必须签 DPA | 所有处理者是否签署 |

> 常见误判：仅「网站能被欧盟访客打开」不算 Art.3(2) 的「提供商品/服务」，
> 需要存在主动招揽的客观迹象（EDPB 3/2018 指引）。

## 二、处理原则（Art.5）

| 项 | 原则 | 检查点 |
|---|---|---|
| 5(1)(a) | 合法、公平、透明 | 是否有合法性基础；告知是否到位 |
| 5(1)(b) | 目的限制 | 是否存在目的外二次使用 |
| 5(1)(c) | 数据最小化 | 每个字段是否都必要 |
| 5(1)(d) | 准确性 | 是否有更新/纠错机制 |
| 5(1)(e) | 存储限制 | 是否定义留存期限并真的删除 |
| 5(1)(f) | 完整性与保密性 | 技术与组织措施是否到位 |
| 5(2) | **问责** | 能否举证上述全部 |

## 五、数据主体权利（Art.15-22）

| 权利 | 条款 | 要点 |
|---|---|---|
| 访问权 | 15 | 提供副本 + 处理信息 |
| 更正权 | 16 | 更正不准确、补充不完整 |
| 删除权/被遗忘 | 17 | 含撤回同意、非法处理、反对成功等情形 |
| 限制处理权 | 18 | 争议期间暂停处理（存储除外） |
| 可携权 | 20 | 仅适用于基于同意/合同 + 自动化处理 |
| 反对权 | 21 | 直接营销**绝对**可反对，无需理由 |
| 自动化决策 | 22 | 有法律/重大影响的，需人工介入与异议权 |

## 六、控制者义务

| 条款 | 义务 | 时限/条件 |
|---|---|---|
| 25 | 设计与默认的数据保护 | 设计阶段 |
| 30 | 处理活动记录（ROPA） | 长期维护；监管首查文件 |
| 32 | 安全措施（加密、假名化、访问控制、可恢复性） | 持续 |
| 33 | 向监管机构报告泄露 | **知悉后 72 小时内** |
| 34 | 向数据主体通报泄露 | 高风险时，不得无故延迟 |
| 35 | 数据保护影响评估（DPIA） | 高风险处理前 |
| 37-39 | 数据保护官（DPO） | 三类情形强制设立 |

## 七、跨境传输（Art.44-49）

| 机制 | 条款 | 适用 |
|---|---|---|
| 充分性认定 | 45 | 欧盟委员会认定该国保护水平充分 |
| 标准合同条款 SCCs | 46(2)(c) | 需配合 TIA 与补充措施 |
| 约束性公司规则 BCRs | 47 | 集团内部跨国有约束规则 |
| 特定例外 | 49 | 明示同意、合同必需等，个案偶尔使用 |

SCCs 不等于免死金牌：Schrems II（C-311/18）要求评估目的国政府访问法律，
必要时采取加密、密钥自持等补充措施。

## 八、处罚（Art.83）

| 上限 | 适用 |
|---|---|
| 2000 万欧元或全球年营业额 4%（较高者） | 基本原则、合法性基础、同意、数据主体权利、跨境传输 |
| 1000 万欧元或全球年营业额 2%（较高者） | 安全措施、ROPA、DPIA、泄露通知、DPO 等义务 |
