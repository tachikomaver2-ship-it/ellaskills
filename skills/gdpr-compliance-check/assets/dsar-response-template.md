# 数据主体权利响应回执模板

> 用于回复访问 / 更正 / 删除 / 限制 / 可携 / 反对请求。
> 1 个月内必须回复；拒绝或延期都需明确说明理由与救济途径。

---

## 模板 A：请求已完成

**主题**：关于您的数据主体权利请求（编号 DSAR-____）的处理结果

尊敬的 [姓名]：

我们于 [日期] 收到您依据 GDPR 第 [15/16/17/18/20/21] 条提出的请求，
现已处理完毕，特此回复。

**1. 请求内容**
[概述请求类型与范围]

**2. 处理结果**
[二选一]

- 已完成：我们已 [提供数据副本 / 更正数据 / 删除数据 / 限制处理]，
  完成时间为 [日期]。
- 部分完成：我们已完成 [部分]，其余部分未能完成，理由见下。

**3. 涉及的数据类别**
[列出类别：如账号信息、订单记录、设备日志]

**4. 接收方（如适用）**
我们已将您的请求同步至以下接收方：[名称或类别]。

**5. 您的救济途径**
如您对本次处理结果有异议，可以：
- 回复本邮件要求复核；
- 向您所在国的数据保护监管机构投诉；
- 通过司法途径寻求救济。

联系人：[DPO 或负责人姓名 / 邮箱]
[公司全称]
[日期]

---

## 响应要点检查

- [ ] 在 1 个月内回复（延期通知也须在此期限内发出）
- [ ] 身份验证不过度收集新证件
- [ ] 覆盖全部系统：主库、备份、日志、缓存、第三方
- [ ] 拒绝时写明具体条款依据
- [ ] 提供救济途径
- [ ] 全程留档（Art.5(2)）
- [ ] 请求人行使权利**不得收费**（除非明显无理由或重复，Art.12(5)）
